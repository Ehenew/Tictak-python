# 🕹️ Tic-Tac-Toe (Python Terminal Game)

This is a simple terminal-based **Tic-Tac-Toe** game written in Python. It's a two-player game where each player takes turns placing their marker (`X` or `O`) on a 3x3 board until someone wins or the game ends in a tie.

## 📌 Features

- Two-player game (Player 1 vs Player 2)
- Random player selection to start the game
- Clean board display in the terminal
- Win and tie detection
- Option to replay after each game
- Input validation for correct moves

- Loops and input handling
- List indexing and game logic
